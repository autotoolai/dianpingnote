# 点评笔记被折叠或搜不到怎么办

> 正式发布地址：[dianping-note.aiautotools.com/knowledge/note-folded-hidden](https://dianping-note.aiautotools.com/knowledge/note-folded-hidden) ｜ 官网源码：[GitHub 仓库](https://github.com/autotoolai/dianpingnote)

> **一句话答案**：先分清是折叠还是违规：折叠查 5 项（重复内容、别家水印、敏感词、外链、批量发布），违规查后台违规记录并申诉；折叠期间越急着多发越难恢复，别删了重发同一条。

## 折叠和违规的区别

**结论**：两者后果不同、处理方式相反，先分清。

| | 折叠 / 降权 | 违规 |
|---|---|---|
| 后台提示 | 通常没有明确提示，或只写「内容未通过审核」 | 明确的违规记录、条款、扣分 |
| 你自己看得到 | 看得到，在「我的内容」里 | 看得到 |
| 别人搜得到 | 搜不到 | 搜不到 |
| 点分享链接 | 打不开内容 | 打不开内容 |
| 账号影响 | 单条内容推不动 | 可能影响账号整体推荐、扣分 |
| 处理方式 | 自己改内容重做 | 申诉 + 整改 + 等待 |

**最容易搞混的一点**：折叠是**内容级**的，违规是**账号级**的。所以先看后台有没有违规记录，这决定了后面所有动作。

## 确认自己这条是不是被处理了

三条判断路径，从简单到麻烦：

**路径一：后台违规记录**

商家后台 → 内容管理 / 违规记录。能看到明确的处理原因、条款、扣分就是违规。

**路径二：换关键词搜**

用**同义词**或**更宽的词**搜自己的内容：

- 原标题搜不到，但用更宽的词能搜到 → 索引或权重问题，偏折叠。
- 换什么词都搜不到 → 更可能是被处理或内容本身没被收录。

**路径三：换个身份看**

用没登录的账号，或者让朋友搜一下。这能区分「只有我看不到」和「所有人都看不到」。商家后台的预览有时和自己看到的不一样。

## 五种常见成因

**1. 内容重复**

**结论**：这是折叠最常见的原因。同一个账号近期发过高度相似的内容，这一条被当低质处理。

看最近 5 到 10 条，是不是有换皮改字的情况。详细判断见 [点评笔记没流量的原因排查](note-limited-traffic)。

**2. 带着别的平台的水印**

画面里有抖音、小红书、微博的 logo、用户名、贴纸、界面元素，都可能被当成「非本平台原创内容」。

处理办法：裁掉边缘，重叠水印用遮盖或修图，视频重新剪掉带水印的片段。

**3. 敏感词和违规表述**

**结论**：哪怕是正常业务描述，碰到平台词库也会被拦。

容易被误伤的：

- 绝对化用语：最好、第一、顶级、100%、唯一、永久
- 功效承诺：治疗、治愈、包瘦、保证学会
- 医疗和金融类：疗效、处方、投资回报
- 引导站外：加微信、私聊、扫码、详询（大部分平台都算外链导流）
- 数字电话和价格绝对值

**排查方法**：把正文拆成词组，逐个搜一下；或者把长句删掉，只留最核心的描述，看哪一段触发了。

**4. 外链和导流**

正文里的网址、微信、二维码、微信号、手机号，都容易被判定为站外导流。

改法：把联系方式放到平台允许的字段里（比如门店电话、门店地址），正文里不写。

**5. 批量行为**

同 IP、同设备、多账号、短时间集中发布，是典型的批量特征。**折叠期再加速发布，会让账号的问题从单条变成整体。**

## 自查清单

按顺序走，不要跳：

1. 查后台违规记录。有违规 → 走申诉，不要继续发。
2. 对比最近 5 条内容，找重复。有重复 → 重做，别小改。
3. 逐张图、逐帧视频看水印、贴纸、界面残留。有 → 裁或修。
4. 扫正文敏感词和站外信息。有 → 删。
5. 看标题和正文的表述是否夸大或承诺效果。有 → 改成客观描述。
6. 确认这条素材不是从别的平台直接搬的。是 → 重剪重写。

## 处理顺序

**结论**：改完之后，重发一条**新的**，不要删了重发同一条。

- **重发要换素材、换角度、换标题**，不只是换个时间。平台算的是内容本身的重复度。
- **先停几天再发**。折叠通常有恢复期，连着发容易让模型把你锁在「批量发布」的判断里。
- **一次改一个变量**。同时改内容又改时间，你不知道是哪个起了作用。
- **记录处理过程**。记下每条被折叠的内容、原因判断、整改动作，下次能看出规律。

## 多久能恢复

**结论**：没有官方时限，取决于触发的是什么。

| 情况 | 恢复的一般节奏 |
|---|---|
| 单条重复折叠 | 停 2 到 3 天，改完重做，正常情况下新内容不受影响 |
| 带水印被判低质 | 改掉后新内容正常 |
| 敏感词被拦 | 改掉词后新内容正常 |
| 账号级限流 | 需要更长，可能是周级；期间发布量越少恢复越快 |
| 明确的违规扣分 | 申诉 + 等待审核结论 |

**判断恢复的信号**：先发一条内容质量明显高于平时的笔记，如果它的曝光回到正常水平，说明账号没问题；如果依然没有推荐，问题在账号层面，要先处理违规再谈别的。

## 常见的错误做法

- **删了重发同一条**：没用。推荐计算看的是当前内容本身，删多少次都一样。
- **删除所有旧内容**：不解决折叠，还会让你失去有正常表现的旧内容做对比。
- **折叠期加大发布量**：通常会让情况变差，从单条折叠变成账号级限流。
- **换个号继续发同样内容**：内容重复的判定和账号无关，新号同样会被判，还会浪费一个新号。
- **只改标题不改素材**：如果折叠原因是图片或视频，标题改多少都没用。

## 用工具能省的部分

排查这件事，工具能做的是**把证据摆到你面前**：

- 每条笔记保留完整的发布状态和失败原因，折叠和有明确违规能区分开，不用凭印象。
- 发布节奏自动错开，避免人为造成批量特征。
- 折叠期暂停发布、到期恢复，这两件事靠手动纪律很容易失控。

[点评笔记助手](https://dianping-note.aiautotools.com/) 的本地笔记池会保留每条笔记的状态流转记录，能帮你回溯「哪段时间、哪个账号、发了什么、结果如何」，这是判断规律的基础数据。

**但内容层面的整改只能人来做**：哪句文案踩了词、哪个画面有水印、这条和上条像不像——工具不知道你的意图和素材来源。

---

**一句话结论**：先分清折叠和违规，折叠就查重复、水印、敏感词、外链、批量行为五项，逐项改掉发一条新的；折叠期少发，别删了重发，越急越糟。
