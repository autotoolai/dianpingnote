# 状态词典

> **一句话答案**：笔记在流水线里有 3 个状态轴：采集、二创、发布。一条笔记可发布的条件是「采集 = 已下载」且「二创 = 已完成」，满足后才进入发布队列。


笔记在流水线里有三个状态轴：**采集 → 二创 → 发布**。列表上显示的就是这三个轴。

## 采集状态

| 你看到的 | 含义 | 常见下一步 |
|---|---|---|
| 待下载 | 已入库，还没开始下 | 等完成即可 |
| 下载中 | 正在拉原视频或图片 | 等完成 |
| 已下载 | 本地文件确实在 | 进入二创 |
| 缺文件 | 库里有记录但本地文件不在了，仍待发布 | 点「重新处理」补下 |
| 已失败 | 下载失败，可以重试 | 点「重新处理」 |
| 源失效 | 原内容已被删除，无法自动下载 | 忽略或删掉 |
| 已清理 | 已发完或不再需要，不补下 | 无需处理 |

## 二创状态

| 你看到的 | 含义 |
|---|---|
| 待二创 | 媒体已就绪，还没生成发布文案 |
| 写文案 | 正在生成标题、正文和标签 |
| 叠标题中 | 正在把标题叠到视频画面顶部（图文没有这一步） |
| 已完成 | 可以进发布池 |
| 待补题 | 没产出可用标题，需要人工补或重试 |
| 已失败 | 文案或叠标题失败，可「重新处理」 |

## 可发布

```text
采集 = 已下载  且  二创 = 已完成
```

满足这条的笔记才会进入发布队列。图文笔记要求图片已在本地且二创完成。

## 发布状态

| 你看到的 | 含义 |
|---|---|
| 待发布 | 已认领或排队中，等上传 |
| 发布中 | 正在上传 |
| 已发布 | 成功，并已绑定某个蓝 V |
| 发布失败 | 上传失败，会释放认领可重试 |

一条笔记只会由一个蓝 V 发布，其它蓝 V 不会再抢。连续上传失败达上限的笔记会被隔离，需要在笔记页手动「重新处理」。

## 笔记页顶部的筛选

| 筛选 | 含义 |
|---|---|
| 全部 | 所有笔记 |
| 可发布 | 已经可以发 |
| 需处理 | 下载失败、缺文件、二创失败、发布失败 |
| 已发布 | 已经成功发出 |

## 名词速查

| 界面用语 | 说明 |
|---|---|
| 补全详情 | 把主页清单补成可下载的正文与媒体地址 |
| 叠标题 | 把标题烧到视频画面顶部 |
| 可发布 | 已下载且二创完成、可进发布池 |
| 后台运行 | 发布时不弹出浏览器窗口 |
| 电脑唤醒后补发 | 到点没跑或休眠后续自动再跑 |
| 蓝 V | 经营宝下的门店账号，一笔记一蓝 V |
