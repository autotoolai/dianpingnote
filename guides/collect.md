# 采集与登录

> **一句话答案**：采集用小号登录小红书、抖音、快手或 B 站这 4 个平台，粘贴创作者主页链接后设定每日定时，软件会自动扫一遍新内容；也可以直接粘单条笔记链接补进来。主页扫描与笔记直采都支持，自动补全详情并下载原片与图文。


## 登录采集平台

去 **采集** 页，用一个小号登录你要采的平台（小红书、抖音、快手、B 站等）。登录状态只保存在本机。

采集账号和经营宝蓝 V 是两套账号：采集用小号，发布用蓝 V。不要把经营宝账号拿来登录采集平台。

## 添加创作者主页

在采集页粘贴主页链接，然后二选一：

| 操作 | 说明 |
|---|---|
| 立即采集 | 现在抓一次，适合刚加的主页 |
| 每日定时 | 设定每天抓取的时刻，到点自动跑 |

定时采集要求软件当时在运行。电脑关机或休眠错过的，唤醒后软件会补跑当天任务。

## 笔记直采

临时看到一条好内容，粘贴单条链接就能采。直采不套用主页的定时，也不受内容类型偏好限制：粘什么采什么。

## 采集后发生什么

```text
主页清单
  → 补全详情：把清单补成可下载的正文与媒体地址
  → 入库：笔记进入本地笔记池
  → 下载：拉取原视频 / 图片到本地
```

状态从「待下载」到「下载中」再到「已下载」。视频下载完还会再生成一个叠好标题的成片。

## 内容类型偏好

在设置里选 **全部 / 仅视频 / 仅图文**，默认「仅视频」。

- 主页定时采集和发布认领都按这个偏好走。
- 直采不受限制。
- 只过滤不删除，改回来还能看到。

## 补全失败怎么办

采集页顶部的健康条会显示补全和下载问题，点进去可以看具体是哪条主页、什么原因。

| 现象 | 处理 |
|---|---|
| 补全失败很多 | 一键重试；仍失败多半是采集平台登录过期，重新扫码 |
| 下载失败 | 到笔记页「重新处理」，会回到待下载 |
| 源失效 | 原内容已被删除，无法自动补下；可以忽略或删掉 |
| 缺文件 | 数据库里有记录但本地文件不在了，去笔记页重新处理 |
| 主页不更新 | 确认设了每日定时，且软件当时在运行 |

## 注意事项

- 采集只是把公开内容拿下来给你参考，发布前请自行确认内容合规，并遵守各平台服务条款。
- 采集来源建议选和你门店品类接近、风格可借鉴的主页，跨品类的内容改写意义不大。
