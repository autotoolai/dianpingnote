# 安装包与运行环境

> **一句话答案**：安装包约 820 MB，已内置 Chrome 与 FFmpeg，不需要另装浏览器也不需要显卡。需要 Windows 10 或 11 的 64 位系统，预留 5 GB 磁盘、4 GB 以上内存。


## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 或 Windows 11，64 位 |
| 磁盘 | 至少预留 5 GB（安装包 + 素材与视频） |
| 内存 | 4 GB 以上 |
| 浏览器 | 不需要另装，安装包已内置 Chrome |
| 网络 | 登录经营宝、采集平台、文案模型接口需要联网；发布上传也需要 |

## 安装包里有什么

| 组件 | 是否随安装 | 说明 |
|---|---|---|
| 主程序、后台服务、托盘 | 是 | 桌面窗口 + 系统托盘 + 本机服务 |
| Chrome | 是 | 约 450 MB，发布时使用，不需要系统另装 |
| FFmpeg | 是 | 约 300 MB，用于视频叠标题 |
| 文案生成通道 | — | 走官方在线服务，本机不落地模型文件，也不需要显卡 |

## 安装步骤

1. 下载安装包（联系销售或在试用开通时获取）。
2. 运行安装程序，按提示完成安装。
3. 从开始菜单或桌面快捷方式启动「点评笔记助手」。
4. 文案能力开箱可用。在「设置 → 文案模型」里能看到通道状态。

## 安装后立刻做的两件事

在「设置 → 系统」里打开：

- **开机后自动运行**：电脑开机后软件自动起来，定时任务不会漏。
- **关闭窗口后留在托盘**：点关闭只是隐藏窗口，下载和发布继续。

## 常见安装问题

**提示缺少组件或安装中断**
先确认系统是 64 位 Windows 10/11；再尝试以管理员身份运行安装程序。

**安装后打开提示未检测到 Chrome**
安装包已内置 Chrome，一般不会出现；如果确实提示，在「设置 → 系统」里重新检测浏览器路径，必要时联系售后。

**下载很慢或一直失败**
多为网络问题。软件不落地任何模型文件，文案统一走官方在线通道；请确认网络畅通后重启软件重试。

**杀毒软件拦截**
软件会调用内置浏览器做自动化上传，部分安全软件会误报。加信任后重试，仍有问题请把日志发给我们。
