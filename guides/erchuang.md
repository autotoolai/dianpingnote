## 选文案来源

去 **设置 → 文案模型**，三选一：

| 选项 | 说明 | 计费 |
|---|---|---|
| **官方云端 API** | 默认，装好即用，不需要任何 Key、不需要显卡 | 计入发布条数，月订阅已包含 |
| 自备 API | 你自己的 OpenAI 兼容接口（DeepSeek、通义等） | 自备算力版，不限条数 |

官方云端 API 是我们的服务，开箱即用，日常发笔记就用它；需要改用自备接口时，在「设置 → 文案模型」里随时切换，不影响正在排队的笔记。

选自备接口属于自备算力版，需要联系销售单独开通。

## 发布文案

在 **二创** 页可以配置：

- **标题、正文、标签**：生成后可以逐条手动改；
- **文案偏好**：语气、长度等，改一次对之后处理的笔记生效。

二创只改写文案，不做配音、不做字幕翻译、不做画面特效。原始素材和生成的成片都保留，方便你对比。

## 叠标题

视频笔记会把发布标题叠到画面顶部。

- 标题太长时按设定字号自动缩放，尽量不超出画面宽度。
- 叠完的成片单独保存，原片保留，随时重出。
- 想调整效果，改设置后对之后处理的笔记生效；已经处理好的笔记可以在笔记页重新处理。

## 图文处理

图文笔记没有画面可叠，改为处理底部水印：

- 按设置遮盖底部水印图标区域，保留图片主体；
- 可以设置最多展示几张图片，控制笔记长度。

## 二创卡住了怎么办

| 你看到的 | 含义 | 处理 |
|---|---|---|
| 写文案 | 正在生成标题、正文和标签 | 等一会儿 |
| 叠标题中 | 视频标题正在往画面上叠 | 等一会儿 |
| 待补题 | 没产出可用标题 | 人工补标题，或点重新处理 |
| 已失败 | 文案或叠标题失败 | 点「重新处理」，回到待二创 |

二创完成的笔记会变成「可发布」，进入发布队列。

## 关于文案生成

文案统一由官方在线服务生成，本机不落地任何模型文件，也不需要显卡或大内存。

- 需要网络与已激活的授权；两者缺一会在「设置 → 文案模型」里提示。
- 生成失败不会阻断发布，可人工补标题或点「重新处理」重试。
- 运行环境与网络要求，详见 [安装包与运行环境](/guides/install)。
